# Using React Components in MDX

<BlogParagraph>

One of the most powerful features of MDX is the ability to use React components directly in your markdown!

<Callout type="info" title="Pro Tip">
  You can import and use any React component in your MDX files. This makes your content interactive and engaging!
</Callout>

  name: string
  email: string
}

const user: User = {
  name: 'John Doe',
  email: 'john@example.com'
}

## Why This is Awesome

1. **Interactive Content** - Add buttons, forms, or any React component
2. **Consistent Styling** - Use your design system components
3. **Type Safety** - Full TypeScript support for your components
4. **Reusability** - Write once, use everywhere

<Callout type="info">
  You can even nest components! This callout is inside a list item.
</Callout>
